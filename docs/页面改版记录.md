# PaperWeave 页面改版记录

日期：2026-10-20（Asia/Shanghai）。

依据用户提供的设计意见，将视觉方向收敛为“科研编辑部 × 瑞士现代排版”。仅修改页面结构、样式、渲染主题和前端反馈；PDF 解析、分块分析、证据匹配、模型 API 协议和下载文件名保持不变。

## 修改文件

- `AGENTS.md`：简短可复用 UI 约束。
- `src/paperweave/static/index.html`：首页布局与上传区域，保留原有 DOM IDs 和 API 契约；增加配置读取失败提示、进度语义。
- `src/paperweave/static/dashboard.html`：精简看板结构、引用标记、对话框语义。
- `src/paperweave/static/dashboard.css`：四级字阶、8px 间距、中性配色、移动端与焦点样式。
- `src/paperweave/static/dashboard.js`：导图配色与选中提示、键盘操作、筛选状态与焦点恢复。
- `src/paperweave/render.py`：同步初始导图的显示主题，不改分析和数据结构。
- 浏览器回归、示例 HTML、截图和 README 同步更新。

## 主要变化

1. 删除视觉噪声：不再用圆角外框、虚线框和装饰色层层套住上传区域。
2. 建立编辑式排版：以留白、对齐、细线与页码/引文标记组织信息，移动端保持可读字号。
3. 统一阅读体验：首页和单文件离线看板使用同一设计系统；保留并验证搜索、导图、证据和下载交互。

## 核查来源

- 用户附件中的 Scientific Editorial × Swiss Modernism 建议。
- https://vercel.com/design/guidelines （实际打开核对焦点、键盘、触控、状态和响应式规则）。

这次没有引入字体 CDN、组件库、动画库或其他运行依赖。导出看板继续支持 file:// 离线使用。

## 实测结果

- 完整自动化回归：16 passed，含本地 HTTP 模拟模型的浏览器级上传链路。
- 最终颜色与布局 UI 复验：4 passed。
- 1440px / 390px 首页和看板：无页面横向溢出、无未处理页面错误。
- 断网 file://：搜索、来源定位、双图、明暗主题、缩放/收展、四类导出及下载 HTML 重开均通过。
- 辅助文字对比度 4.754:1，主按钮文字 5.462:1，引用标记 5.402:1；机器数据见 outputs/contrast-review.json。
- 修复了截图检查发现的桌面索引/底部说明重叠。

测试使用本地确定性响应，没有调用真实外部模型。UI 改版不改变此前关于实际模型验收仍需真实参数的说明。
