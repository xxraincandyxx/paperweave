## 模拟数据与真实模型的区别

自动化测试和操作取图使用合成教学 PDF、确定性测试响应或本地模拟 Chat Completions 服务。图文操作手册明确保留模拟标识。相关通过结果说明软件流程与页面交互可用，不证明真实模型的科学理解或分析准确率。

当前没有使用真实外部模型完成新论文分析。实际使用时需配置可用接口，并人工核对研究问题、方法、贡献、实验数值、局限及原文证据。

## 如何复现

在项目根目录安装好运行环境后执行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe examples/build_demo.py
.\.venv\Scripts\python.exe -m pytest -q --basetemp .test-tmp
```

生成真实结果后，可按 [图文操作手册](评委使用说明.md) 关闭本地服务并断网，再从另一个文件夹重新打开下载的 HTML，检查搜索、节点证据、双图切换、缩放和导出。
