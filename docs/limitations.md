## 使用边界

- 扫描件、加密文件、图像公式及纯图表需要额外预处理或人工核对；文本型 PDF 也可能漏提取图注。
- 关键数值、作者贡献、局限与应用边界应结合原页检查。摘录匹配不能代替语义核对，分块完成也不等于科学信息没有遗漏。
- 当前没有页面内取消或断点续跑。若需要中止，先停止旧服务并确认进程退出，再重新提交；新任务会从头处理。
- 模型接口的可用性和分析质量需要用实际配置测试。正常运行不会以教学响应自动代替失败的真实模型请求。
