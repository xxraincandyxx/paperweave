# 测试与验收记录

## 实测环境

Windows，CPython 3.12，Microsoft Edge（通过 Playwright headless 驱动），Node 24（构建时）。实际依赖版本见 requirements 与 package-lock。

## 已执行

- 真实 Mermaid mindmap / flowchart parse；mindmap render 产出 SVG。
- 四页合成 PDF：3 个分析块，46 个来源片段，末页信息进入最终节点，全部片段被分配并完成分析。
- 本机 HTTP Chat Completions 服务：通过正常 `LLM` 网络客户端请求，可验证配置模型 ID、生效接口和端到端输出。服务响应为明确标记的确定性测试内容。
- 单文件看板：浏览器离线模式、file:// 打开，无 HTTP(S) 请求；索引、搜索、节点详情、页码定位、缩放、展开折叠、双导图、深浅主题和四种导出。
- 导出的 HTML 再次在离线浏览器打开。
- 移动端 390×844：无页面水平溢出，原生思维导图节点能选中。
- 150 个来源块完整分配到分析块；130 个节点经过多层归纳后无遗漏或重复叶子。
- 伪造引文、未知来源、相反陈述去重、JSON 修复、API 鉴权错误脱敏、加密 PDF、扫描/空白 PDF、跨源/外来主机请求阻断。
- 真实公开《Attention Is All You Need》PDF：15 页、254 个来源片段、7 个块，全块分配到末页；第 14 页提取文字不足有提示，未假定其图像内容已被理解。详见 `outputs/real-pdf-smoke.json`。

首次真实论文检查发现标题被版权说明误识别，随后又发现侧边旋转 arXiv 标识影响字号选择；已结合 ScholarFlow 标题过滤、字体大小与文字方向修复，并添加回归测试。

## 独立离线验收方法

完成一次真实 PDF 处理后：停止 Python 服务，断开网络，把 `dashboard.html` 复制到另一个目录，再双击打开。验证导图显示、搜索、页码原文、折叠/缩放、图类型/主题切换和下载均可用。打开浏览器开发工具 Network 面板应无外部 HTTP(S) 请求。

最终自动化测试：**13 passed**，1 条来自第三方 Starlette TestClient 的弃用提示，不影响当前通过结果。

额外实测本地上传服务返回 HTTP 200，文件选择正确显示，未配置模型时给出错误提示；服务已在测试结束时停止。
