## 必做与工程交付

| 比赛要求 | 当前实现 | 验证与剩余条件 |
|---|---|---|
| 输入 PDF 路径或上传 PDF | `__main__.py analyze`；本地 FastAPI 上传页 | CLI、HTTP、本地页面均可用 |
| 正文提取并保存 | PyMuPDF4LLM 按页提取；`extracted.md/json` | 合成 PDF + 真实 15 页双栏论文已测 |
| 根据实际内容分析主题、问题、论证、贡献、结论与局限 | `analysis.py` 的结构化发现与内容主题归纳 | 功能具备；模型科学内容质量需真实 API 与陌生论文人工核验 |
| 全流程一键，不需要继续输 Prompt 或选结构 | 上传一次或命令一次，自动提取→分析→归纳→编译→校验→导出 | 本地 HTTP 模拟 API 端到端通过；真实验收 API 未测试 |
| Mermaid 导图可渲染 | 改造自 mindmap-generator 的递归编译；两种格式真实解析，思维导图实际渲染 | 浏览器渲染与交互测试通过 |
| 本地离线 HTML 与基础交互 | 单文件内嵌脚本、样式、数据和 PDF；索引、详情、缩放、折叠 | file:// + 浏览器 offline 模式通过，无 HTTP(S) 请求 |
| DeepSeek V4 Pro 配置化 | `.env` / 环境变量中的 API Key、Base URL、模型 ID；不写死模型参数 | 配置与 HTTP 协议已测；精确 ID、权限和服务商参数需主办方通知后实测 |
| 评委提供陌生论文 | 正常路径处理任意文件，不按样例标题选择逻辑；教学响应只在独立 example/test 代码里 | 真实双栏提取已测；陌生论文端到端语义质量待验收 |
| 提交目录与 README 内容 | `src/`、README、requirements、`.env.example`、examples、outputs、许可和测试 | 已齐备；真实队伍名与真实模型示例需补充 |
